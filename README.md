# 蒼海の盟約 — 灰暁の巡礼団

[ゲームを開く](https://juncaglobal.github.io/azure-covenant/)

ブラウザーで遊ぶタクティカルRPG。配信版 **5.5.0**。

- 敵味方の体格、職業別装備、武器、両手保持と攻撃の緩急を改修。
- 27カット・90秒のオープニングを収録。
- オリジナルのオープニング曲「海を越える誓い」（インストゥルメンタル）。
- タッチ操作、セーブ、PWAに対応。

ゲーム配信データは `_release` に格納されています。GitHub Actionsが各ファイルのSHA-256を検証してGitHub Pagesに配信します。

第三者素材のライセンス表記はゲーム内および配信ファイル内に含まれます。

ゲーム本編にはWebGL 2が必要です。3D描画が使えない環境では、オープニングをイラスト版で再生できます。
